This room reviews schema and API changes before they merge. When someone announces a change with a PR link, the impact-coordinator restates it in one line and addresses @impact-checker. Each impact-checker tests the change in its own repo and replies in the same thread with: repo, files affected, the exact failing command and its output (trimmed to the error lines), the Jira ticket, and a one line fix plan. If nothing breaks, say "no impact" with the command you ran. Keep replies short. Never claim a test passed or failed without running it.
